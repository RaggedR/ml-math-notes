# Math

Comprehensive LaTeX mathematics notes covering linear algebra (fundamental subspaces, projections, quadratic forms), probability and statistics, perceptron convergence proofs, and DFT watermarking theory.

## Tech Stack
- LaTeX (pdflatex, amsmath, amssymb, amsthm, TikZ)

## Setup
```bash
pdflatex main.tex
```
